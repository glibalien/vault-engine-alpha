03The core — a deterministic engine and an inferring curator

Vault Engine

System of record. Every change goes through one pipeline. The engine itself never generates text.
Typed notes & schemas
Turn a mess of markdown and random files into a clean, multi-typed relational database — by hand, or let an AI do it for you.
Hybrid search
Lexical + semantic over the whole graph. Local ONNX embeddings, benchmark-tuned ranking.
Durable memory
Tiered consolidation — add, update, contradict. Bi-temporal, deduped, recalled by relevance.
Content extraction
Audio, images, PDFs, office docs become searchable text and get embedded locally.
Settings, two ways in
Every setting is a file in your vault. Edit it in plain markdown, or let an AI caller change it through tools — same validation either way.
Cost tracking & logs
Every paid API call is recorded and priced. Full sync and edit history, nightly backups, health checks.

Vault Curator

The engine keeps the vault correct; the curator keeps it current. It is the one caller that never asks — working the vault while you're not looking, through the same tools, validation and undo as everyone else.
Living wikis
A whole wiki per project or topic — multi-page, templated — written and kept current from your tasks, meetings and notes, at your direction.
Memory harvesting
Reads the day's activity for what's worth keeping, then consolidates it into long-term memory instead of letting it pile up.
Filing & cleanup
Types stray notes, fills missing fields, repairs links, files things where they belong — the ongoing half of turning mess into data.
Scheduled runs
Nightly by default, or on your own cadence. Each pass is metered, logged and reversible like any other caller's.
Optimized for optimizing
Vault Engine lets you point AI at years of mess — random tasks and notes, half-finished files, inconsistent structure — and have it type, link and clean them into usable data.
watch in (DB-only) · atomic render out
